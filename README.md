# Resonant Vessels

A static website exploring resonance, harmonics, and the hidden physics of sound and vibration — from Chladni figures and the Schumann cavity to Tesla's oscillators, alchemical symbolism, and speculative teleportation research.

## Folios (10 pages)

1. **index.html** — Home / gateway to the collection
2. **harmonics.html** — Harmonics & vibrational fundamentals
3. **experiments.html** — Experiments & simulations
4. **figures.html** — Figures & plates
5. **lab.html** — The laboratory
6. **alchemy.html** — Alchemical resonance
7. **tesla_files.html** — The Tesla files
8. **teleportation.html** — Teleportation research
9. **government.html** — Government programs & documents
10. **roundtable.html** — Roundtable discussion

## Structure

- `css/style.css` — site stylesheet
- `js/main.js` — site scripts
- `assets/` — 46 PNG figures, plates, and diagrams

## Deployment

This is a fully static site (no build step). It is deployed via GitHub Pages:

**https://occult-kranti.github.io/resonant-vessels/**

Deployment is automated by `.github/workflows/pages.yml` once the repository's Pages source is set to **GitHub Actions** (Settings → Pages → Source), or alternatively via "Deploy from a branch" (main / root).
